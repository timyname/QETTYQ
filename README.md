# QETTYQ

QETTYQ — mobile-first пилот выбора досуга в Астане. Сначала пользователь отмечает интересы 15 свайпами, затем задаёт время, бюджет и необязательную точку старта. Приложение объединяет live-афишу Sxodim и отдельный каталог реальных мест OpenStreetMap.

**Сайт:** [qettyqapp.anamai.kz](https://qettyqapp.anamai.kz/) — отдельный контейнер на Hetzner, HTTPS. Прежний Sites-адрес оставлен как legacy-релиз с отключённым AI. Фактический статус публикации и проверок: [`docs/STATUS.md`](docs/STATUS.md). Инструкция хостинга: [`deploy/README.md`](deploy/README.md).

## Что уже работает

- onboarding: 15 свайпов, затем время, бюджет и добровольная геолокация;
- полноэкранные карточки: плавное появление сердечка при drag, подтверждение только по отпусканию, undo и ранний выход;
- четыре раздела, горизонтальная карусель, детали, saved, настройки и удаление памяти с подтверждением;
- единый liquid-glass стиль, лимонные акценты, закреплённые шапка и меню; контент прокручивается внутри экрана;
- `/api/events`: реальная афиша Sxodim, фильтр «Сегодня», карточки, цены с неопределённостью и переход к организатору/первоисточнику;
- полноэкранная векторная карта MapLibre/OpenFreeMap с OSM и выбором старта;
- чат с карточками и локальной историей, deterministic fallback без внешней модели;
- планы до пяти мест, дата/время Астаны и переход во внешнюю навигацию;
- пеший путь по улицам через FOSSGIS / OSRM Foot после отдельного согласия, линия на нашей карте, дорожные расстояния и время;
- серверный детерминированный поиск и ранжирование;
- проверка временного окна и unknown-цены;
- 80 реальных POI Астаны из ограниченного импорта Overpass;
- серверный provenance для каждой записи; обязательная общая OSM-атрибуция;
- гостевые сессии, идемпотентные реакции/undo и локальное удаление данных;
- честные режимы `snapshot`, `deterministic`, `estimated route`;
- адаптивный интерфейс и reduced-motion режим.
- форма локального черновика события, без ложного обещания публикации.

## Данные и ограничения пилота

При последней проверке 20 октября 2026 `/api/events` вернул 8 будущих событий. Это результат конкретного ограниченного импорта, не обещание полного покрытия города. Кэш обновляется по запросу после часа; постоянный фоновый cron не запущен. Ближайшие даты имеют приоритет перед рекламным порядком источника. При отказе источника сохранённые данные помечаются как snapshot/stale. Обновление не обходит ограничения источника.

У этих событий источник не сообщил координаты: события видны в афише и чате, но ложные маркеры на карте не ставятся. На карте — 80 POI из OSM snapshot. Изображения категорий — собственные иллюстрации, не фотографии конкретных мероприятий. Неизвестные цена, язык и наличие мест не подменяются придуманными фактами. Перед посещением уточните детали у организатора.

Sxodim используется только в рамках разрешённого некоммерческого переиспользования с обязательным credit и ссылкой: [условия](https://sxodim.com/polzovatelskoe-soglashenie). Перед коммерческим запуском требуется согласование прав. Фотографии и полные описания оттуда не копируются. Другие источники — только исследованные кандидаты, не подключённые провайдеры. См. [`data/livedata/README.md`](data/livedata/README.md) и [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).

Помощник ищет реальные события и места, предлагает условия и показывает карточки. На VPS включён GPT-5.5 evidence-RAG: факты/карточки отбирает код, модель формулирует совет и использует проверяемые ID источников. Реальный публичный вызов проверен. Свободный web search выключен; отдельный локальный тест с веб-поиском не означает, что он включён публично. Статус — `/api/assistant/status`. История и предпочтения пока хранятся на устройстве, точная геопозиция — только в текущей странице. Серверные гостевые сессии временные. SQLite-модель согласий/профилей/диалога/визитов подготовлена, но публичное долговременное запоминание ещё не подключено.

До дорожного расчёта план показывает оценку по прямой без вымышленной линии. После согласия отдельный пешеходный сервис FOSSGIS возвращает реальную дорожную геометрию, которую рисует MapLibre. Время остаётся оценкой, доступность проходов и посещений нужно уточнять. Постоянный SQLite-лимитер допускает не чаще одного запроса за 1,5 секунды на весь сайт и до 200 запросов в сутки. Это ограниченный пилот без SLA, не промышленная навигация. Продолжение доступно во внешних Google Maps / 2ГИС / Apple Maps. Авто/такси/автобус не выдают вымышленные ETA. Google Routes API не рисуется поверх OSM, Google Maps JavaScript API не используется. ORS-адаптер подготовлен для собственного ключа, но не заявляется подключённым.

Постоянная SQLite хранит события/сеансы, происхождение, права источников, кэш и общий AI ledger. До переноса старый AI writer Sites заморожен, D1 экспорт проверен и импортирован с прежним approval ID. Для разрешённого бюджета до $10 резервируется $0.50 на попытку, максимум 20 попыток суммарно, без возврата или сброса при перезапуске/деплое. Неизвестный ответ/учёт расходов блокирует следующие вызовы. Это лимит приложения, не hard stop всего аккаунта OpenAI. Секрет передан отдельно в закрытый runtime-файл, не в Git или Docker-образ. При отказе AI остаётся явно обозначенный подбор по правилам.

Исследованы 10 источников: [`отчёт`](docs/agent-reports/A-sources-vps-20261020.md). Они не становятся автоматически подключёнными провайдерами. Периоды работы кафе и событийная афиша разделены; evaluator часов готов, но у текущего OSM snapshot подтверждённых часов нет. Для роста карты нужны разрешённые feeds, координаты и права на медиа, а не догадки модели.

## Локальный запуск

Требуются Node.js 24 и pnpm 11.25.0 (проверенные SQLite runtime и lockfile).

```bash
pnpm install
pnpm data:validate
pnpm dev
```

Откройте `http://localhost:3000`.

Для просмотра с телефона в одной Wi-Fi-сети запускайте с выбранным локальным IPv4 Mac (не публикуйте dev-сервер через проброс портов):

```bash
QETTYQ_DEV_LAN_HOST=192.168.0.106 pnpm dev --hostname 0.0.0.0 --port 3000
```

На телефоне откройте `http://192.168.0.106:3000`. Замените IP на актуальный адрес компьютера; Mac должен оставаться включённым. Геолокацию проверяйте на публичном HTTPS-сайте: на LAN HTTP браузер может её заблокировать.

Проверки:

```bash
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm build
pnpm submission:check
```

Повторный импорт POI делает один ограниченный запрос к публичному Overpass API и перезаписывает локальный snapshot:

```bash
pnpm data:import:poi
```

Не запускайте импорт на каждый пользовательский запрос. Для production нужен подходящий extract, self-hosted Overpass или коммерческий провайдер. Данные © OpenStreetMap contributors, ODbL 1.0.
