# QETTYQ

QETTYQ — mobile-first пилот выбора досуга в Астане на русском, казахском и английском. Первый экран — только выбор языка; затем пользователь отмечает интересы 15 свайпами, задаёт время, бюджет и необязательную точку старта. Приложение объединяет live-афишу Sxodim и отдельный каталог реальных мест OpenStreetMap.

**Сайт:** [qettyqapp.anamai.kz](https://qettyqapp.anamai.kz/) — отдельный контейнер на Hetzner, HTTPS. Прежний Sites-адрес оставлен как legacy-релиз с отключённым AI. Фактический статус публикации и проверок: [`docs/STATUS.md`](docs/STATUS.md). Инструкция хостинга: [`deploy/README.md`](deploy/README.md).

## Как сделан пилот

- **Интерфейс:** Next.js, TypeScript и mobile-first компоновка для экрана телефона.
- **Подбор:** серверное ранжирование объединяет интересы пользователя, временное окно, бюджет и доступные сведения о местах.
- **AI-помощник:** ограниченный внутренний intent-plan → получение данных → ответ GPT-5.5. Карточки, ссылки, даты, бюджет и допустимость результата контролирует код; внутренние рассуждения не публикуются.
- **Данные:** live-события Sxodim отделены от snapshot-каталога OpenStreetMap. У каждой записи сохраняется источник и статус свежести.
- **Карта и маршрут:** MapLibre отображает OpenFreeMap/OSM, а FOSSGIS Foot возвращает дорожную геометрию пешего пути.
- **Надёжность:** при отказе источника используются явно обозначенные snapshot или fallback, неизвестные значения не превращаются в нули и подтверждённые факты.
- **Хранение:** SQLite используется для сеансов, кэша, provenance, лимитов и добровольной памяти. HttpOnly identity cookie, независимые scopes, TTL, восстановление, отзыв и удаление; скрытое запоминание не включается.
- **Публикация:** приложение работает в изолированном Docker-контейнере за Nginx с HTTPS.

- onboarding: 15 свайпов, затем время, бюджет и добровольная геолокация;
- полноэкранные карточки: плавное появление сердечка при drag, подтверждение только по отпусканию, undo и ранний выход;

- `/api/events`: реальная афиша Sxodim, фильтр «Сегодня», карточки, цены с неопределённостью и переход к организатору/первоисточнику;
- полноэкранная векторная карта MapLibre/OpenFreeMap с OSM и выбором старта;
- чат с карточками, локальной историей и отдельной добровольной серверной памятью; deterministic fallback без внешней модели;
- планы до пяти мест, дата/время Астаны и переход во внешнюю навигацию;
- пеший путь по улицам через FOSSGIS / OSRM Foot после отдельного согласия, линия на нашей карте, дорожные расстояния и время;
- серверный детерминированный поиск и ранжирование;
- проверка временного окна и unknown-цены;
- 749 реальных POI Астаны из открытого OSM/Geofabrik snapshot; у 265 опубликованы часы работы;
- серверный provenance для каждой записи; обязательная общая OSM-атрибуция;
- гостевые сессии, идемпотентные реакции/undo и локальное удаление данных;
- честные режимы `snapshot`, `deterministic`, `estimated route`;
- адаптивный интерфейс и reduced-motion режим.
- форма локального черновика события, без ложного обещания публикации.

## Данные и ограничения пилота

При проверке 21 октября 2026 `/api/events` вернул 16 будущих событий (20:18 UTC 20 октября). Это результат конкретного ограниченного импорта, не обещание полного покрытия города. Кэш обновляется по запросу после часа; отдельный `qettyq-events-refresh.timer` также прогревает его каждый час независимо от посещений. Оба пути используют один постоянный lease и не обходят ограничения источника. Ближайшие даты имеют приоритет перед рекламным порядком источника. При отказе источника сохранённые данные помечаются как snapshot/stale.

Для опубликованных адресов есть офлайн-индекс 29 517 адресных точек OSM и строгое сопоставление улицы и полного номера дома. Неоднозначность остаётся неизвестной; полученная точка маркируется derived и не обещает вход. На карте — 749 POI из OSM snapshot на 19 октября, не live-каталог: 265 расписаний, 222 набора cuisine и 118 адресов. Изображения категорий — собственные иллюстрации, не фотографии конкретных мероприятий. Неизвестные цена, язык и наличие мест не подменяются придуманными фактами.

### Общий узел данных и внешние анализаторы

На VPS работает постоянная SQLite-база. Контракт для Threads-анализатора, отдельная producer-авторизация, идемпотентные batches, provenance и карантин описаны в [docs/DATA_HUB.md](docs/DATA_HUB.md). Приём: `POST /api/internal/data-hub/batches`; публичный проверенный каталог: `GET /api/data-hub/catalog?city=astana`. Ключ передаётся только через `Authorization: Bearer`, никогда в URL. Непроверенные права Threads не превращаются в право хранить публикации: до согласования сохраняются только безопасные метаданные карантина, без исходного payload. Принятые свежие события разрешённых источников объединяются с афишей для карты и поиска.

Постоянный ежечасный сбор Sxodim уже работает на сервере; остальные feed/API требуют согласования. POI-экстракт обновляется отдельным офлайн-импортом, **не** скачивается ежечасно на занятом VPS. Воспроизводимый импорт: [scripts/poi-extract/import.mjs](scripts/poi-extract/import.mjs). Список источников и прав: [docs/DATA_SOURCE_ACCESS_20261021.md](docs/DATA_SOURCE_ACCESS_20261021.md). Четыре запроса отправлены: [docs/SOURCE_OUTREACH_20261021.md](docs/SOURCE_OUTREACH_20261021.md); отправка не означает полученное разрешение.

Sxodim используется только в рамках разрешённого некоммерческого переиспользования с обязательным credit и ссылкой: [условия](https://sxodim.com/polzovatelskoe-soglashenie). Перед коммерческим запуском требуется согласование прав. Фотографии и полные описания оттуда не копируются. Другие источники — только исследованные кандидаты, не подключённые провайдеры. См. [`data/livedata/README.md`](data/livedata/README.md) и [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).

Помощник ищет реальные события и места, предлагает условия и показывает карточки. GPT-5.5 выполняет внутренний разбор контекста и короткий ответ, без hosted tools и бесконечных циклов. До двух вызовов используют один прежний резерв бюджета; факты/карточки отбирает код. Семантический запрос не ослабляет исходные ограничения. Статус — `/api/assistant/status`.

Серверная память доступна через `/api/memory`: четыре независимых согласия `profile`, `dialogue`, `visits`, `ai_transfer`, хранение 24 часа или 30 дней. Восстановление требует случайного HttpOnly cookie, а не переданного из клиента ID. Запрос без opt-in не создаёт identity. Диалог ограничен последними 24 сообщениями; отзыв scope удаляет его данные. Полное удаление очищает память и cookie; приватные резервные копии могут сохраняться до семи дней. Язык устройства отдельно от согласия на память. Точная геопозиция не является полем профиля и остаётся в текущей странице; свободный текст проходит консервативную редакцию координат, но это не универсальный детектор адресов.

Google Places Text Search (New) использует отдельное согласие и прежний прикладной бюджет до $10: не более 100 невозвратных резервов по $0.10. Выбранный владельцем `GOOGLE_MAPS_SERVER_API_KEY` передан из защищённого `.env.local` в серверный секрет без ротации; значения в Git, клиенте и логах нет. Флаги включения не заменяют разрешения API в Google Cloud. Google-контент не сохраняется, не отправляется LLM и не ставится на OSM-карту: отдельные mapless-карточки с обязательными credits открываются в Google Maps. Блюдо, цена и пригодность по времени не подтверждаются одним результатом поиска; при строгом бюджете неизвестные цены не обходят фильтр.

21 октября Google403 устранён через Google Cloud: в проекте именно выбранного ключа был выключен Places API(New). API включён; существующий Pay as you go не менялся. Ключ оставлен прежним, ограничения сужены до IP сервера и одного Places API(New). Публичный `probe-google-public.mjs` получил HTTP200/live,5заведений/5расписаний. В ledger2 консервативных резерва по$0.10, включая предыдущий отказ; это не сумма счёта Google. Общий прикладной cap$10 не сброшен и не является лимитом всего Google Cloud аккаунта. `scripts/smoke-vps-release.mjs` по умолчанию проверяет отказ без согласия и не тратит Google quota.

До дорожного расчёта план показывает оценку по прямой без вымышленной линии. После согласия отдельный пешеходный сервис FOSSGIS возвращает реальную дорожную геометрию, которую рисует MapLibre. Время остаётся оценкой, доступность проходов и посещений нужно уточнять. Постоянный SQLite-лимитер допускает не чаще одного запроса за 1,5 секунды на весь сайт и до 200 запросов в сутки. Это ограниченный пилот без SLA, не промышленная навигация. Продолжение доступно во внешних Google Maps / 2ГИС / Apple Maps. Авто/такси/автобус удалены из внутреннего планировщика. Google Routes API не рисуется поверх OSM, Google Maps JavaScript API не используется. ORS-адаптер подготовлен для собственного ключа, но не заявляется подключённым.

Постоянная SQLite хранит события/сеансы, происхождение, права источников, кэш и общий AI ledger. До переноса старый AI writer Sites заморожен, D1 экспорт проверен и импортирован с прежним approval ID. Для разрешённого бюджета до $10 резервируется $0.50 на попытку, максимум 20 попыток суммарно, без возврата или сброса при перезапуске/деплое. Неизвестный ответ/учёт расходов блокирует следующие вызовы. Это лимит приложения, не hard stop всего аккаунта OpenAI. Секрет передан отдельно в закрытый runtime-файл, не в Git или Docker-образ. При отказе AI остаётся явно обозначенный подбор по правилам.

Исследованы 10 источников: [`отчёт`](docs/agent-reports/A-sources-vps-20261020.md), [расширение](docs/agent-reports/A-source-expansion-20261020.md). Они не становятся автоматически подключёнными провайдерами. Sxodim adapter допускает до 24 detail pages / 50 occurrences за один общий часовой refresh; это предел, не обещание количества. Периоды работы кафе и событийная афиша разделены. Импорт и проверка наблюдаемых недельных часов готовы, но у текущих 80 POI подтверждённых часов нет. Попытка расширения Overpass вернула 502/406; snapshot сохранён, ограничения не обходились. Для роста карты нужны разрешённые feeds, координаты и права на медиа, а не догадки модели.

## Локальный запуск

Требуются Node.js 24 и pnpm 11.25.0 (проверенные SQLite runtime и lockfile).

```bash
pnpm install
pnpm data:validate
pnpm dev
```

Откройте `http://localhost:3000`.

Для просмотра с телефона в одной Wi-Fi-сети запускайте с выбранным локальным IPv4 Mac (не публикуйте dev-сервер через проброс портов):

```bash
QETTYQ_DEV_LAN_HOST=192.168.0.106 pnpm dev --hostname 0.0.0.0 --port 3000
```

На телефоне откройте `http://192.168.0.106:3000`. Замените IP на актуальный адрес компьютера; Mac должен оставаться включённым. Геолокацию проверяйте на публичном HTTPS-сайте: на LAN HTTP браузер может её заблокировать.

Проверки:

```bash
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm build
pnpm submission:check
```

Повторный импорт POI делает один ограниченный запрос к публичному Overpass API и перезаписывает локальный snapshot:

```bash
pnpm data:import:poi
```

Не запускайте импорт на каждый пользовательский запрос. Для production нужен подходящий extract, self-hosted Overpass или коммерческий провайдер. Данные © OpenStreetMap contributors, ODbL 1.0.
