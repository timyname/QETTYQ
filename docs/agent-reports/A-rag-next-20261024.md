## Implemented contract

- `retrieval/source-permission.ts`: typed `RetrievalSourcePolicy`, `SourcePolicyResolver` and `sourcePermission(sourceId, use, resolver, now)`. All operations require explicit persist+display; generation additionally requires `sendToLlm`; embedding additionally requires `embed`. Display alone is allowed when LLM is false. A missing/throwing lookup, missing/false grant, revoked grant or invalid/expired explicit review expiry denies use. An omitted review expiry means this grant supplies no review-expiry deadline; it does **not** refresh event/cache data or bypass their independent expiry rules. An explicit null expiry is unknown and rejected.
- `retrieval/service.ts`: `retrieveAuthorizedEventEvidence(data,text,context,now,{resolveSourcePolicy,use?,semanticText?})`. Resolver is mandatory. Rejected source records are removed before matching/ranking/top-three; a permitted fourth record is not lost behind denied earlier ones. Exclusions expose only fixed technical reason enums. No policy cache, new provider or new facts.
- `tests/evals/baseline-adapter.ts` now passes the **existing unchanged** `corpus.sourcePolicies` to that production wrapper. Corpus/gold/manifest and judgments are unchanged. The adapter is current production-function evaluation, not an immutable historical implementation.
- Independently reported dialogue regression: immediate Russian category-postfix negation such as “Театры не хочу, лучше стендап” now negates the theatre mention. Exact verb scope and optional “мне/нам” only; “не только”, arbitrary modifiers and later clauses do not become negation. No fuzzy entity identity or guessed venue goal.
- Lexical version v3; trace recorder writes v3 while the read schema accepts both v2/v3. Existing valid stored v2 traces remain readable, with no row deletion/migration or tracing flag change.

The orchestrator separately owns `application-source-policy.ts`, runtime/DB adapters, host contracts, API wiring, `answerPilotChatWithEvents` and final integration. This agent does not claim those consumers are deployed merely because the pure wrapper passes.
