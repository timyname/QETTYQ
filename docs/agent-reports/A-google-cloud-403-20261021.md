Дата:21 октября2026,Asia/Aqtobe. Scope: существующий Google Cloud project/key QETTYQ; без нового ключа, подписки, платежных данных, изменения остальных проектов или перезапуска VPS.

## Причина и проверка

В Chrome были два разных Maps key/project. Отпечаток первого не совпал с защищённым `.env.local`; его настройки не сохранялись. Отпечаток ключа второй вкладки совпал с выбранным владельцем server key. В этом проекте Places API(New) был выключен; billing уже привязан, текущий план Pay as you go. Следовательно включение API было проверяемым исправлением; проблему HTTP referrer другого ключа к текущему не приписываем.

## Сделано

- Включён только Places API(New), UI подтвердил enabled состоянием кнопки Disable.
- Ограничения выбранного ключа сужены с anyapplication до IPv4 `46.224.184.192` и с32 Maps API до одного Places API(New). IPv4 подтверждён read-only route на VPS.
- Ни Rotate/Createcopy/Delete, ни создание billing account/платной подписки не использовались. Значение ключа сохранено; server SHA256 совпадает с владельцем.
- Один контролируемый запрос к публичному QETTYQ по запросу «рамен»: HTTP200/statuslive/5заведений/5расписаний. Это поисковые результаты, не подтверждение меню, цены или доступности. Google data не сохраняются, не передаются LLM и не попадают на OSM.
- Скрипт удалил только свою тестовую гостевую сессию. OpenAI не вызывался.
