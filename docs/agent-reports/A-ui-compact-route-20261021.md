# A5/A6 · Компактный маршрут и возврат после выбора старта

Дата: 21.10.2026. Scope: только UI маршрута, передача действий из PilotApp, новые строки RU/KK/EN и E2E. Server/API/config/package/PWA/mobile не изменялись.

Финальный статус: **44/44 E2E PASS в одном чистом прогоне, 2.9 минуты, workers=2**. TypeScript и scoped ESLint PASS. Новые address-match + i18n unit: 11/11 PASS. Ниже сохранена история ранних отказов и их исправлений, не актуальный блокер.

## UX-контракт и реализация

- Карта — основная поверхность. По умолчанию над dock находится короткая полупрозрачная jade/pearl-панель, на 390×844 около 234 px высотой.
- В сводке: дата Астаны, приблизительное общее время или неизвестный старт, пеший режим, число остановок, расстояние с явным основанием, неизвестная стоимость и превышение ограничений. Ничего неизвестного не превращается в ноль.
- «Остановки и условия» раскрывает панель до 62% viewport с внутренним scroll. Внутри: дата/время, старт, последовательность, длительности посещений, запас, бюджет, отдельная кнопка изменения условий, пояснение оценок, согласие на конкретного дорожного провайдера и внешние карты.
- «Начать маршрут» остаётся видимым под внутренней прокруткой. Это внешняя Google Maps-навигация с явным пояснением передачи выбранного старта; не бронирование.
- Атрибуция OpenStreetMap/OpenFreeMap и дорожного провайдера не удалена и остаётся вне панели/dock.
- Геолокация меняет origin без перехода в бюджет. На плане запускается пересчёт и появляется «Обновляем маршрут…»; ответ не навигирует пользователя принудительно.
- Ручной выбор точки и отмена возвращают на вызывавший экран: из условий — в условия, из плана — в план, с обычной карты — на карту. На обычной карте добавлена доступная текстовая кнопка ручного старта, в том числе как альтернатива отказу GPS. В плане изменённый origin пересчитывает план.
- «Изменить старт» и «Изменить условия» теперь разные действия; GPS не служит скрытой ссылкой в бюджет.
- Выбранная дата вынесена в parent React state и передаётся как initialDeparture после remount. GPS и ручное обновление origin сохраняют дату; успешный новый buildPlan и явное изменение условий сбрасывают её. Ключ plan.id сохранён, поэтому прежняя дорожная геометрия не переживает пересчёт.

## Аудит кнопок

| Элемент | Действие / ограничения |
|---|---|
| На карту | Возврат к интерактивной карте |
| Share | Системный share либо clipboard; точный origin не входит в текст; отключён при пересчёте |
| Остановки и условия | Toggle с aria-expanded и aria-controls; работает клавиатурой |
| Дата / Сейчас | Время Астаны, валидируется существующим кодом, ошибки не скрываются |
| Выбрать / Изменить старт | Ручной picker на карте; возврат/отмена сохраняют контекст |
| Моё местоположение | Явный браузерный запрос, остаётся текущий экран; отказ сообщает ручную альтернативу |
| Название остановки | Детальная карточка источникового места, возврат к плану |
| Удалить остановку | Пересчёт; последнюю остановку удалить нельзя, busy блокирует повтор |
| Изменить условия | Явный переход к параметрам времени/бюджета, не связан с GPS |
| Routing consent / calculate / clear | Отдельное согласие для набора точек; busy/нет старта/нет согласия блокируют вызов; очистка удаляет геометрию |
| Внешние карты / Начать маршрут | Существующие walking deeplinks; не изображают поездку автобусом/такси |
| Dock / logo / settings | Существующие переходы сохранены; источник и атрибуция не спрятаны |

Это аудит связей по коду и выбранных E2E-сценариев, не заявление о клике каждого внешнего сайта или проверке физических iPhone.
