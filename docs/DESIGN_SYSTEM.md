# QETTYQ · дизайн-система

Направление: тактильный городской журнал, которым удобно управлять одной рукой. Тёплый бумажный фон, тёмный бирюзовый текст, редакционная гарнитура Prata для смысловых заголовков и Manrope для интерфейса. Сетка видна как лёгкая картографическая подложка; яркий лаймовый используется только для доказательств и статусов.

Карточки имеют радиус 20–32 px, тонкую линию и мягкую глубокую тень. Motion объясняет смену состояния: короткое появление экрана, пружинная замена discovery-карточки и прогресс. При `prefers-reduced-motion` движение почти полностью выключается. Все действия доступны кнопками без свайпа.

Ключевые состояния: onboarding, constraints, discovery, results, empty и API error. Источники, unknown-поля и приблизительный маршрут визуально не скрываются.
