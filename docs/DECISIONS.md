# Решения

## Local-only memory, размер медиа и Sybil budget · 24.10.2026

- Афиша использует одну геометрию rail100%/min-width0 и16:10 frame; содержимое posters contain, без генеративного заполнения/обрезки текста. Venue/detail размеры не менялись. Проверены крайние natural aspect ratios,404/missing и длинные названия.
- readForDialogue — отдельный local-only scope, не разрешение на AI/Google передачу. Только действующий opaque memory cookie+guest, независимые profile/dialogue grants/TTL. Старый relative-date текст не переигрывается после смены дня Астаны; это ограничение до trusted per-turn timestamps, не удаление UI истории.
- Публичный getStatus проверяется до выбора memory scope. Недоступный/throw status фиксирует deterministic execution на весь запрос; если квота позже изменится, этот запрос всё равно не вызывает модель. AI-available ветка по-прежнему только readForAI/ai_transfer. Local replay блокирует Google enrichment; свежая client history имеет приоритет.
- Fresh request nondefault money/time поля защищаются от local old turns без persistent autoconfirm. Budget/strictness/basis/partySize связаны: false не должен теряться только потому, что совпадает с default. Текущая реплика может предложить новый лимит; session сама не меняется.
- Sybil gateway не создаёт новый ledger/approval: прежние USD10, USD0.50 no-refund reservations, global pending/block, fixed session cooldown/daily и UUID/step1..4. Ограничены endpoint/model/tokens/bytes/tools/retries/timeout. Adapter пока не автоматически подменяет upstream engine; прямой ключ ему не выдавать.
- Владелец подтвердил app-only GLM в ZCode. Использовать существующий интерфейс для независимого ограниченного review можно; извлекать OAuth/превращать app subscription в API нельзя. GLM opinions — synthetic hypotheses, не реальные отзывы, конверсия или прохождение всех функциональных тестов.


## Разговорный контекст и R2 без нового биллинга · 24.10.2026

- Увеличен не provider prompt, а bounded deterministic replay:20 сообщений/6KiB вместо6 при той же общей границе14KiB. Provider slice6 и все модели/token/reservation caps неизменны. Память читается только при действующих scopes; assistant turns не трактуются как факты.
- Историческая тема/дата/отрицания исправляются последней положительной user репликой. Подтверждённые money/time поля из /api/context восстанавливаются перед текущим сообщением; strict non-null budget защищён и без field provenance вместе с basis/party. Default120/null не выдаются за подтверждение. Goal остаётся мягкой темой диалога, не вечным lock. Explicit current changes — proposal, не autoconfirm.
- Live canary нашёл второй parsing pass, превращавший canonical «без еда» обратно в food после правильного dialogue. parseContext теперь использует общий immediate-scope negation helper, сохраняя bounded EN verb/preposition/article grammar и positive-clause controls. Дополнительный Google enrichment в этом пути не начинается.
- Lexical v2 ищет known exact names/translations до top3, но не делает fuzzy entity merge и не выдумывает amenities/цены/географию. Gold/manifest не менялись; archived baseline fbe5923 отделён от current adapter. Holdout не используется для исправления его конкретных провалов.
- Минимальные R2 traces: explicit flag, default OFF, additive SQLite migration2;24h TTL, hashed session/entity IDs,30/session10000global. Write/read failures не ломают ответ, delete failure не маскируется успехом. Не собираются тексты/GPS/URLs/providerraw/tokens/cost; основной ledger остаётся авторитетным.
-16 издательских afisha artworks +2 venue JPEG живут вне Git; только18 approved bytes по manifest входят в image. Rights scope/expiry/credit/no-store не ослаблялись. Доступная публичная картинка без точного venue identity не является пригодным фото.
- Sybil: владелец подтвердил nghiahsgs/Sybil-Swarm. Устанавливать только isolated no-key local backend; не передавать existing key в engine без общего hard cap. Синтетические отзывы не равны browser QA/реальным метрикам/прохождению RAG tests.


## Publisher media и происхождение памяти · 24.10.2026

- Фото от издателя допускаются только в явно некоммерческом пилоте по опубликованным условиям, с кредитом/ссылкой и отдельным reviewed manifest. Это не CC-лицензия и не утверждение об известном фотографе. Любое известное third-party ограничение/expiry/revoke отключает выдачу.
- Скачанные publisher JPEG не попадают в публичный Git. В runtime входят только12 проверенных файлов:1706916 bytes, aggregate SHA256 `f4d2479c4363d70722f5c3e217082cbdc008ec6d3cc6702fe57d47f4e8e982ed`. Нет универсального image proxy; только фиксированный SHA route, проверка байтов и no-store. Коммерциализация требует нового разрешения.
- Identity фото — source event URL либо точное имя+наблюдённый адрес/общее адресное здание; близость сама по себе не матч. Commons park match основан на GPS внутри проверенного OSM polygon и визуальном review;2005 год показывается явно.
- Применён frontend-design для иерархии атрибуции: короткая строка в ленте, подробные условия в деталях, без изменения Pearl/Jade системы.
- Право видеть сохранённый диалог не равно ai_transfer. Provenance server/device/legacy_unknown сохраняется при reload и для производных ответов. Без свежего действующего согласия protected history не включается в AI payload; lookup failure fail-closed, UI не очищается.
- R1 — измерение существующего top3 matcher, не его подмена: frozen snapshot/synthetic отдельно,40 reviewed labels, returned Recall@10 явно над ≤3 результатами. LLM generation/injection и internal candidate recall не измерены. R2 trace/retention/delete и source capability gate остаются следующими стадиями.


## Упорядоченный черновик и автоматический дорожный расчёт · 21.10.2026

- «Оценить путь» добавляет/использует выбранную точку в существующем плане, а не заменяет весь план. Лимит5 без тихого вытеснения. Reorder/remove остаются точными replacement-операциями.
- Для уже выбранного старта разрешённый walking adapter вызывается автоматически однократно на упорядоченную геометрию/провайдера; ошибка не запускает retry-loop. Линия рисуется только из валидированного street ответа. Отмена consent прерывает запрос.
- В основной timeline отдельно показываются дорога и посещение, с явной неизвестностью длительности события. Перестановка доступна стрелками и удержанием. Сервер разделяет time/budget violations; UI пересчитывает временной warning и передаёт показанный total в share.
- Никаких новых источников, фото-разрешений, миграций, ключей или бюджета. R0 source audit документирует существующие gaps, а не объявляет новый RAG реализованным.

## Правки iPhone и отдельно разрешённый native Origin · 21.10.2026

- Safe area защищает элементы управления, но не отрезает сцену карты/скроллеров. Шапка прозрачна с отдельными glass city/settings; chat занимает весь viewport с внутренними scroll insets вместо непрозрачного внешнего зазора. Прямой контроль клавиатуры iOS не имитируется: enterKeyHintsearch задаёт системное действие, фирменная лупа отдельной кнопкой. Pinchzoom не запрещён; focus zoom устраняется шрифтом≥16px.
- Map search bounded/offline/source-grounded: адресные точки из датированного индекса, не Google и не скрытый geocoder. Размягчение орфографии предназначено только для списка кандидатов, не автоматического geo identity join. Явный выбор адреса может изменить старт; пустое совпадение не выдумывается. Ввод не попадает в долгосрочную память.
- Первичный route CTA рассчитывает street geometry. External start появляется после успеха, а обход при provider failure явно обозначен «без расчёта». Unknown duration/стоимость не превращаются в zero/feasible. UI формат h/min не меняет арифметику.
- Native origin — отдельное решение владельца после предупреждения об общем `capacitor://localhost`. Консоль действительно приняла и сохранила его; прежниеweborigin/month1000Block сохранены. Env `QETTYQ_2GIS_NATIVE_ORIGIN_APPROVED=true` явный; по умолчанию false. Не разрешать произвольные null/file/custom origins. Native view может сериализовать Location.origin какnull, поэтому разрешён только точный protocol+hostname, не строкаnull.
- Public permissions photo не выводятся из фразы «пилот»: пользователь отдельно разрешил bounded прямое скачивание1оригинала для закрытой проверки. Скачанный файл имеет source/hash/rightsmanifest и не автоматически активирует media grant. Автоимпорт сайтов/соцсетей и расширение разрешённых реальных фото остаются задачами. Компактная заглушка — UX исправление, не решение наполнения.

Ограничение затрагивает все сервисы ключа; localhost/native origins не добавлялись. Для native нужен отдельный согласованный доступ, web-проверка не равна iPhone QA.

Геоданные и значения неизвестных фактов не меняются. Маркеры/route используют palette, не выдуманные внутренние globals SDK.

## Геоданные и ключ 2ГИС · 21.10.2026

Адрес/название не гарантирует точку: exact venue correspondence, источник, свежесть и отсутствие конфликта обязательны; матч остаётся derived и не обещает вход. Event plan неизвестную длительность/итог не заменяет нулём или вымышленными90мин. Строгий generated ID не создаёт координаты.

Существующий `2GIS_API_KEY` server-only. MapGL получает только отдельный `QETTYQ_2GIS_BROWSER_KEY` при exact approval flag; совпадение с server key запрещено. Ключ нельзя объявить безопасным без domain/API restrictions. Пока нового разрешения нет, MapGL выключен, OSM attribution не скрывается. Внешняя навигация2GIS не требует API key. Демодоступ не означает paid subscription или право сохранять весь каталог.

GPS proximity — не conversion/visit proof. Только optional foreground suggestion, отдельное visits consent и явное подтверждение; никакого автоматического background tracking по умолчанию.

Google bundle максимум 1 Enterprise TextSearch + 5 PhotoMedia ($0.035 + 5×$0.007) укладывается в существующий резерв $0.10, без retry/pagination. API сам ничего не включает при пропущенных flags. Это не согласие на долговременную память, не отправка GPS и не передача Google content в модель.

История — контекст, не источник фактов; assistant messages не создают предпочтений. Неоднозначное число без валюты/вопроса о бюджете остаётся неизвестным, не становится деньгами по догадке. Проверенные локальные JPEG публикуются с credits/license/change notices; attribution не скрывается ради дизайна.

Safe-area от native bridge/`env()` применяется один раз. CSS squircle — progressive enhancement, не Apple Liquid Glass API.

## Google Cloud: исправление без смены ключа · 21.10.2026

Настройки менять только после сверки выбранного server key с ключом консоли по SHA256. Старый браузерный ключ другого проекта не трогать. В правильном проекте Places(New) был выключен; включить только его, существующий Pay as you go не менять. Сузить доступ выбранного ключа до IP QETTYQ и Places(New), не выбирать None, не ротировать. Лимит остаётся прикладным$10 с прежним durable ledger, не обещать account-wide Cloud hard cap. Один успешный publicprobe достаточен, платные циклы не нужны.

## Открытый bulk snapshot + независимые producer batches · 21.10.2026

- Не превращать открытый URL/Threads scrape в лицензию. Источник и поля проходят scope/freshness/provenance; без persist права исходный payload не сохраняется даже в карантине. Media grant отдельно от права на факты.
- Общий узел — существующий изолированный VPS SQLite; новый источник не создаёт свой несвязанный silo. APIключ отдельный, на сервере только SHA256; plaintext только в ignored0600 producer handoff. Ключ Google оставлен по явной воле владельца, не выводится и не ротируется агентом.
- OSM/Geofabrik snapshot обрабатывается локально, не на занятом VPS. Локальный osmium cap2GB дал exit137, корректный повтор с5GB успешен; пустой результат не импортирован. Поэтому большой weekly bulk job на VPS не включается. В production продолжает реально работать bounded hourly Sxodim refresh.
- Адресный индекс server-only. Только наблюдаемые multilingual names одной OSM street; не LLM/транслитерация. Полная улица+дом, точка derived, корпус/несколько координат→unknown; самостоятельная проверка обнаружила и закрыла prefix/decimal/corpus cases.
- Route plan.id invalidation сохранена; выбранная дата поднята в parent state и не теряется при origin refresh. GPS остаётся на invoking screen; compact sheet оставляет предупреждения и CTA видимыми.

## Языки, согласованная память и ограниченный reasoner · 21.10.2026

- Первый экран содержит только вопрос о языке и три выбора RU/KK/EN на существующем изображении Астаны с телефоном. Язык устройства хранится отдельно от согласия на серверную память. Пользовательские сообщения, исходные названия и адреса не выдаются за переведённые факты. Frontend-design/design-intelligence сохраняют glass/jade/limon, без нового визуального стека.
- Память — явный opt-in по четырём независимым scopes: profile, dialogue, visits, ai_transfer. Идентификатор — случайный HttpOnly cookie и его серверный хеш, не clientId из JSON. Срок 24 часа или 30 дней; отзыв удаляет соответствующий scope, полное удаление очищает identity и cookie. TTL проверяется запросами и фоновым таймером процесса. Точная геолокация не является полем профиля; редактирование свободного текста не обещает универсальное обнаружение всех адресов. Приватные backups живут до семи дней.
- Публичный GPT-5.5 получает максимум два bounded вызова: внутренний intent JSON (400 output tokens) → проверяемое получение данных → короткий ответ (800). Это не публикация chain-of-thought. Один прежний невозвратный резерв $0.50 покрывает оба вызова; неизвестный accounting закрывает новые вызовы. Прежний approval/SQLite ledger и общий OpenAI cap $10 не сбрасываются.
- Даты, деньги, допустимость и исходные интересы проверяет код. Cuisine-фильтр применяется до top-three ranking; неизвестное меню не становится подтверждением блюда. Права отправки источника в LLM проверяются отдельно от согласия пользователя на передачу памяти.
- Google Places Text Search (New) подготовлен с отдельным разрешённым пилотом до $10: durable reservation $0.10 до каждого вызова, максимум 100, без возвратов/переинициализации. Это прикладной предохранитель, не hard stop Cloud Billing. Только server key, отдельное согласие на запрос, без GPS, retries, фото, сохранения контента или отправки его LLM. Mapless результаты с Google Maps и сторонними credits открываются только в Google Maps, не на OSM. Попавший в чат ключ не используется; до защищённой настройки новый провайдер fail-closed.
- Sxodim разрешённый некоммерческий bounded refresh расширен до 24 последовательных detail pages / 50 occurrences, с проверкой robots/terms и прежним общим часовым lease. Это предел кода, не фактическое число полученных событий. Overpass 502/406 не обходится; старый snapshot остаётся. Недельные часы сохраняются только при наблюдаемом значении и поддерживаемом разборе, иначе unknown.
- Авто/такси/автобус удалены из внутреннего планировщика. Обязательные OSM/OpenFreeMap/FOSSGIS credits остаются компактно видимыми. Геометрия сбрасывается после изменения остановок/времени; оценка по прямой не рисуется как дорожный маршрут.

## Приоритетный контур · перенос на VPS · 20.10.2026

- Пользователь выбрал существующий Hetzner и qettyqapp.anamai.kz; новый платный сервер не покупался. Локальная linux/amd64 сборка с pinned Node24 digest сохраняет память занятого VPS. Отдельный контейнер/UID/каталог/hostname, только graceful proxy reload; generated NPM hosts не редактируются.
- Runtime секрет передан allowlist-скриптом по stdin через host-pinned SSH в mode0600 файл. Ни ключ, ни прочие .env значения не включаются в Docker context/Git/логи. Разрешённый временный SSH-доступ подлежит удалению после проверок, не становится постоянным доступом.
- Node24 SQLite WAL/FULL: события/occurrences/venues/provenance/permissions/cache отдельно от согласий/памяти/AI ledger. Production требует explicit absolute database path. Отсутствие валидного proof при каждом startup закрывает paid AI. $0.50 reserve, $10 cap, unknown accounting fail-closed; hosted search не включается без нового доказанного cost bound.
- Недельные часы заведения и конкретные событийные даты — разные сущности. У source permissions отдельно persist/display/LLM/fetch; новый кандидат не получает разрешение от старого OSM/Sxodim источника. Не выводить pins/фото/цены по догадке; не использовать Google data на OSM вопреки правилам.
- UI сохраняет существующий glass/jade/limon язык; design-intelligence/frontend-design направили плотность/иерархию, а не новый несвязанный редизайн. OSM/OpenFreeMap credits видны, даже если отзыв просил скрыть их.
- Первые реальные AI ответы выявили lexical false-negative для вежливой framing-фразы. Исправлены только scaffolding/category normalization; неизвестные конкретные интересы, рок, даты и бюджет по-прежнему отсекаются кодом. Не заменяем deterministic constraints свободной генерацией.

## Актуальные решения · публичные данные и D1 · 20.10.2026

- Владелец разрешил D1 без отдельной платной подписки; binding `DB` реально provisioned. Durable D1 используется для глобальных резервов AI и ограничителя routing, не выдаётся за durable-хранение гостевых сессий.
- Локальный `.env.local` не публикуется. Повторное использование ключа разрешено, но runtime Secret отсутствует; до защищённого ввода публичный AI fail-closed. Нельзя передавать ключ через stdout, чат или самодельный RPC.
- Публичный GPT-5.5 получает source-evidence RAG без hosted tools: бюджет резервируется атомарно до вызова; неизвестный расход блокирует дальнейшие попытки. 20 × $0.50 — консервативный прикладной резерв до $10, не гарантированный hard cap аккаунта.
- Sxodim-кандидаты сортируются по ближайшим наблюдаемым датам, фактическое начало берётся из detail JSON-LD. До 8 карточек, обновление после часа при запросе, не cron и не полное покрытие Астаны. Source-ссылки видны по последнему требованию владельца.
- Нельзя считать координаты места доказательством координат мероприятия; неподтверждённые события не ставятся на карту. Сторонние афиши требуют отдельно подтверждённых прав.
- Google Routes не используется поверх OSM. Предпочтён отдельный пешеходный провайдер на OSM, отдельное согласие на передачу точек, настоящая GeoJSON-геометрия и явная оценочность времени. Финальный статус приведён в отчёте релиза.
