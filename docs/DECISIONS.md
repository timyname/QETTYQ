# Решения

1. Один full-stack Next.js проект без микросервисов.
2. Первый вертикальный сценарий использует реальный небольшой OSM snapshot; сетевой импорт не выполняется в пользовательском запросе.
3. При отсутствии ключа работает детерминированное объяснение, которое явно не называется AI/RAG.
4. До routing-provider расстояние и время помечаются приблизительными.
5. Визуальное направление — тактильный городской журнал; тяжёлые 3D-зависимости отложены.
6. Пятнадцать onboarding-изображений имеют тип `category_illustration` / `synthetic_visual`; они не выдаются за фотографии реальных мест или событий. Текст, цена и расписание всегда остаются отдельными UI/data-слоями.
