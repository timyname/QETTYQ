# Решения

## Приоритетный контур · перенос на VPS · 20.10.2026

- Пользователь выбрал существующий Hetzner и qettyqapp.anamai.kz; новый платный сервер не покупался. Локальная linux/amd64 сборка с pinned Node24 digest сохраняет память занятого VPS. Отдельный контейнер/UID/каталог/hostname, только graceful proxy reload; generated NPM hosts не редактируются.
- Runtime секрет передан allowlist-скриптом по stdin через host-pinned SSH в mode0600 файл. Ни ключ, ни прочие .env значения не включаются в Docker context/Git/логи. Разрешённый временный SSH-доступ подлежит удалению после проверок, не становится постоянным доступом.
- Node24 SQLite WAL/FULL: события/occurrences/venues/provenance/permissions/cache отдельно от согласий/памяти/AI ledger. Production требует explicit absolute database path. Миграция схемы только при startup; queries не создают схему на запросе. Публичная долговременная память не выдаётся за подключённую.
- Старый Sites AI writer сначала заморожен успешным deployment/env5, затем проверен полный D1 export:0rows,next_offset=null. Импорт сохраняет approval ID и не сбрасывает локальные резервы. Отсутствие валидного proof при каждом startup закрывает paid AI. $0.50 reserve, $10 cap, unknown accounting fail-closed; hosted search не включается без нового доказанного cost bound.
- Недельные часы заведения и конкретные событийные даты — разные сущности. У source permissions отдельно persist/display/LLM/fetch; новый кандидат не получает разрешение от старого OSM/Sxodim источника. Не выводить pins/фото/цены по догадке; не использовать Google data на OSM вопреки правилам.
- UI сохраняет существующий glass/jade/limon язык; design-intelligence/frontend-design направили плотность/иерархию, а не новый несвязанный редизайн. OSM/OpenFreeMap credits видны, даже если отзыв просил скрыть их.
- Первые реальные AI ответы выявили lexical false-negative для вежливой framing-фразы. Исправлены только scaffolding/category normalization; неизвестные конкретные интересы, рок, даты и бюджет по-прежнему отсекаются кодом. Не заменяем deterministic constraints свободной генерацией.

## Актуальные решения · публичные данные и D1 · 20.10.2026

- Владелец разрешил D1 без отдельной платной подписки; binding `DB` реально provisioned. Durable D1 используется для глобальных резервов AI и ограничителя routing, не выдаётся за durable-хранение гостевых сессий.
- Локальный `.env.local` не публикуется. Повторное использование ключа разрешено, но runtime Secret отсутствует; до защищённого ввода публичный AI fail-closed. Нельзя передавать ключ через stdout, чат или самодельный RPC.
- Публичный GPT-5.5 получает source-evidence RAG без hosted tools: бюджет резервируется атомарно до вызова; неизвестный расход блокирует дальнейшие попытки. 20 × $0.50 — консервативный прикладной резерв до $10, не гарантированный hard cap аккаунта.
- Sxodim-кандидаты сортируются по ближайшим наблюдаемым датам, фактическое начало берётся из detail JSON-LD. До 8 карточек, обновление после часа при запросе, не cron и не полное покрытие Астаны. Source-ссылки видны по последнему требованию владельца.
- Нельзя считать координаты места доказательством координат мероприятия; неподтверждённые события не ставятся на карту. Сторонние афиши требуют отдельно подтверждённых прав.
- Google Routes не используется поверх OSM. Предпочтён отдельный пешеходный провайдер на OSM, отдельное согласие на передачу точек, настоящая GeoJSON-геометрия и явная оценочность времени. Финальный статус приведён в отчёте релиза.

## 20.10.2026 · стекло и live-афиша

Объединяем glass-fill/edge/shine/depth/blur на контролах, dock, шапке и sheets; длинный текст оставляем на более матовой подложке. Лимонный цвет означает активный раздел или главное действие, не случайное украшение. Frame 100dvh; прокрутка внутри main/messages.

Sxodim facts используются только в разрешённом некоммерческом пилоте с credit. Обновление по запросу после часа, ограниченное число страниц; stale fallback не объявляется live. Координаты не угадываем, фотографии не копируем. Чат получает события из того же кэша отдельно от POI. Внешняя платная модель не включается.

1. Один full-stack Next.js проект без микросервисов.
2. Первый вертикальный сценарий использует реальный небольшой OSM snapshot; сетевой импорт не выполняется в пользовательском запросе.
3. При отсутствии ключа работает детерминированное объяснение, которое явно не называется AI/RAG.
4. До routing-provider расстояние и время помечаются приблизительными.
5. Визуальное направление — тактильный городской журнал; тяжёлые 3D-зависимости отложены.
6. Пятнадцать onboarding-изображений имеют тип `category_illustration` / `synthetic_visual`; они не выдаются за фотографии реальных мест или событий. Текст, цена и расписание всегда остаются отдельными UI/data-слоями.
7. Визуальные mockup-экраны хранят только композицию, свет, глубину и плотность.
   Текст, карта, источник и фактические значения всегда собираются React-слоем.
8. P0 design pack состоит из 28 PNG; состояния 01, 06, 07 и 15 не дублируются
   растровыми файлами, потому что являются SVG/CSS или производными состояниями.
9. Liquid glass применяется только к floating controls, sheets и navigation;
   базовые поверхности остаются матовыми и не превращаются в glassmorphism.
10. Нижний dock из четырёх разделов появляется только после формирования первой
    ленты: `Для тебя`, `Поиск`, `Карта`, `Профиль`. На onboarding и route focus
    flow он скрыт; планы доступны из профиля и route context.
11. Penpot используется как локальный open-source design workspace. PNG остаются
    reference layers; переходы также фиксируются в Markdown и click-flow, чтобы
    архитектура не зависела от одного редактора.
12. Поиск объединяет direct search и assistant; настройки открываются отдельной
    шестерёнкой в header и не занимают tab.
13. Основной набор UI-иконок — Lucide SVG. AI-raster UI icons, emoji и вырезанные
    из генераций controls не используются; генерация разрешена только для media.
14. По указанию владельца от 20.10.2026 сначала собирается редактируемый Penpot,
    затем согласованная версия переносится в web app. Публичная публикация в этом
    проходе остановлена. Новый источник дизайна — страница `02 · App assembly · editable`.
15. Пятнадцать вариантов одной колоды не считаются пятнадцатью самостоятельными
    экранами продукта: 44 основные схемы + settings 45 + 14 визуальных вариантов 05.
16. Ручной выбор точки возвращает в контекст 10. Поиск начинается отдельной
    кнопкой «Собрать варианты». Создание события в прототипе показывает локальный
    черновик, не отправку на модерацию. Карта прототипа явно помечена схемой.
17. Уточнение владельца 20.10.2026: колода05 становится full-bleed, без постоянных
    reaction CTA и белого footer. Два круглых контрола: undo и двухэтапный переход
    к условиям с расширением плашки влево. `design/penpot/SWIPE_BEHAVIOR.md`
    заменяет старые правила колоды. Penpot preview click не считается drag-жестом;
    настоящий pointer swipe и хранение реакций — отдельная последующая вёрстка.
18. Горизонтальная выдача14 — просмотр карточек без записи like/skip. Медиаслой
    примерно3:4 находится внутри настоящего clipped card вместе с контентом и CTA.
    Карты имеют отдельный clipped viewport; тяжёлые тени не используются внутри
    маски переписки. Логотип всех основных макетов ведёт в «Для тебя»14.
19. Все отрисованные enabled controls прототипа имеют действие/состояние; честно
    недоступные системные операции показывают объяснение. Примеры настройки,
    диалог и share preview не объявляются сохранением данных, AI или clipboard.
20. После ревью основные сценарии перенесены в отдельный `PilotApp` вместо композиции старых несвязанных разделов. Старый Home сохранён как `LegacyHome`, не удалён. Публичный showcase отдельно от full-stack приложения и пока не обновляется.
21. Последнее уточнение свайпа: feedback — обычное сердечко/текст без плашки и рамки. Возврат к центру отменяет намерение; скорость не является самостоятельным commit. Порог проверяет код; клавиатурная альтернатива видна только при фокусе.
22. Карта пилота использует OSM/Leaflet и группирует близкие точки. Статические schematics Penpot не выдаются за Google Maps. Haversine не превращается в геометрию дороги; без routing-provider навигационной линии нет.
23. Потребительский DTO не содержит технического provenance. Обязательная OSM/иная лицензионная атрибуция остаётся, как и подтверждённые ссылки организатора. Неизвестные контакты/цены не подставляются.
24. Создать частный локальный черновик можно без заявления о подтверждённом организаторском статусе. Публикация и eligibility — отдельные неготовые серверные процессы; сохранение черновика не вызывает fake moderation.
25. Проверка Origin сравнивает фактический HTTP Host: Next может нормализовать Request URL в localhost. Cross-site запросы всё равно блокируются; x-forwarded-host не становится доверенным источником.
26. Локальные копии сторонних инструментов в ignored `tmp/` не относятся к исходникам приложения для ESLint. Правила для `src`, `tests` и проектных scripts не ослабляются.
# Решение владельца 20.10.2026: публичный AI до $10

После успешного отдельного локального теста владелец выбрал: «Включить публично, общий бюджет до $10». Это разрешение на реализацию и активацию при соблюдении общего лимита, не разрешение публиковать ключ или обходить обязательный setup Sites.

Активация требует защищённого серверного ключа через OpenAI Developers / `openai-platform-api-key`, постоянного атомарного резервирования общего бюджета и ограничений запросов. До этих проверок публичный AI остаётся выключенным. Текущий Site не имеет D1 binding. Плагин OpenAI Developers предложен, установка пока не подтверждена. Память процесса, браузер и локальный файл нельзя использовать как глобальный публичный бюджетный счётчик.
