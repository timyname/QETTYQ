# Ограничения текущей версии

- snapshot не гарантирует текущие часы работы, цену или наличие места;
- точный пеший маршрут не построен;
- события и занятия с расписанием не импортируются;
- генеративная модель не подключена;
- состояние discovery живёт в браузере до перезагрузки;
- интерфейс использует внешнюю загрузку Google Fonts; production может перейти на лицензированное локальное размещение.
