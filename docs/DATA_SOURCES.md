# Источники данных

Первый источник — OpenStreetMap через публичный Overpass API. Импорт ограничен 80 именованными POI в небольшой bounding box Астаны, запускается вручную и не используется как backend пользовательских запросов. Хранятся название, координаты, категория, адрес при наличии, OSM ID, URL и время получения.

Атрибуция: © OpenStreetMap contributors. Лицензия данных: ODbL 1.0. Реестр условий: `data/source-registry.json`.

Public Overpass рассчитан на небольшие запросы и может быть перегружен; production-интеграция требует другого способа поставки данных.

## Живая афиша Астаны — проверка 20 октября 2026

Подключён ограниченный адаптер [Sxodim / Астана](https://sxodim.com/astana), отдельно от базы POI. [Условия издателя](https://sxodim.com/polzovatelskoe-soglashenie) допускают некоммерческое использование с указанием автора и ссылкой. Подключение ограничено некоммерческим пилотом; это не универсальная лицензия на фотографии и не разрешение для будущего коммерческого сервиса. Required credit «Давай Сходим» и ссылка на событие сохраняются, включая карточки чата и evidence.

При refresh адаптер проверяет robots и условия, получает публичный index и максимум восемь detail pages. Даты и цены читаются из `schema.org/Event`/явных price labels; дата из индексной карточки служит только приоритетом обнаружения, не источником occurrence. Ссылки упорядочиваются по ближайшим датам, потому что верх index содержит рекламные/продвигаемые карточки, не хронологический календарь. Скрипты страницы не исполняются, redirects не следуются, чужие аккаунты/API не используются. Фото не скачиваются.

Фактический ограниченный refresh `2026-10-20T16:15:55.319Z`: 22 candidate links, 8 detail requests, 8 подтверждённых будущих occurrences, 0 rejected. Ближайшее начало — `2026-10-21T11:00:00.000Z` (16:00 Астана). Пример [страницы ближайшего события](https://sxodim.com/astana/event/lekciya-i-master-klass-udivitelnyy-mir-mongol-zurag). Это результат указанного запроса, не гарантия нынешнего количества и не полная афиша города. Ранее верхние промо-карточки давали менее близкие даты; исправлен порядок discovery, реальные даты не сдвигались.

`sourceUrl` — страница факта у агрегатора, не обязательно сайт организатора. Отдельный `organizerUrl` заполняется только если `Event.organizer.url` прямо указан в исходном JSON-LD и URL прошёл проверку публичного HTTPS. Во всех восьми occurrences этого refresh поле отсутствовало: значение `null`, официальные домены не угадывались. Эти ссылки сами по себе не запускают внешний fetch и не предоставляют права scrape нового домена.

## Поиск и evidence для AI

`src/server/ingestion/event-evidence.ts` выполняет детерминированную выборку: явная категория/текст названия, дата в `Asia/Almaty`, начало не в прошлом, известный статус, бюджет и строгие unknown-ограничения. Поддержаны сегодня, завтра, выходные, текущая неделя, ISO-дата и русская дата; для запроса «сейчас» учитывается ближайшее доступное окно и известный конец события. Если дата не названа, это поиск будущих событий, а не обещание «сегодня». Неоднозначные свободные формулировки не являются полноценным семантическим пониманием.

Unknown price не становится бесплатной, price-from не становится exact. При строгом бюджете неизвестная/минимальная итоговая цена исключается; неизвестная единица платной цены для группы не умножается произвольно. Неизвестные длительность, дорога, язык, единица цены и наличие мест остаются предупреждениями; попадание в календарное окно не доказывает, что весь визит с дорогой укладывается в свободное время.

`eventEvidence[]` содержит на каждую отобранную карточку ID, name, ISO start/end, типизированную price, sourceUrl, organizerUrl nullable, fetchedAt, dataMode, freshness, requiredCredit и unknowns. Точные координаты пользователя, HTML, source description и инструкции веб-страниц в пакет не входят. URLs и карточки принадлежат серверным фактам, не создаются моделью. Режим генерации AI отдельно настраивает оркестратор; этот data adapter не выполняет платных AI-вызовов.

## Обновление и хранение

Refresh выполняется по запросу не чаще одного раза в час в пределах одного isolate/edge-cache, с single-flight. Нового cron/монитора нет. Cache API Cloudflare локален дата-центру, не является глобальным distributed rate limit или постоянной базой. Модульная память эфемерна. Snapshot от 20 октября остаётся датированным read-only fallback; при сбое показан `snapshot/stale`, а не «live». Изменение условий источника блокирует fallback до проверки. Cache key v2 отделяет новый порядок поиска от старого promo-order payload.

Реальные binary posters не хранятся. Правила для отдельной одобренной афиши и маркированных проектных иллюстраций находятся в `data/media-policy.json` и `docs/agent-reports/A-event-media.md`. Ticketon, Kino.kz, Astana Ballet и другие площадки остаются кандидатами/ссылками, не подключёнными API. Широкий парсинг и вывод всех городских киносеансов этой реализацией не подтверждаются.
