# QETTYQ click flow

Локальный кликабельный прототип поверх утверждённых PNG-состояний.

Запуск из корня проекта:

```bash
python3 -m http.server 4178
```

Открыть `http://localhost:4178/design/prototype/`.

Прототип проверяет информационную архитектуру и переходы. Он не заменяет
production-компоненты и не превращает raster UI в источник фактических данных.
