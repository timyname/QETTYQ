## Структура каждого экрана

430×932 — размер основной области приложения, без корпуса телефона. Компактные confirmation overlays имеют собственную меньшую геометрию. Manrope, цвета из `qettyq-screen-layers.json`, Lucide SVG. Имена слоёв разделены по назначению: `chrome`, `media`, `content`, `candidate`, `action`, `navigation`, `map`, `chat`, `route`.

Картинки — image fills, надписи — настоящие Text layers. Кнопки — отдельные boards с label/icon и native interactions. Для тебя / Поиск / Карта / Профиль — четыре постоянных пункта. Настройки — отдельная gear overlay45.

05 и 05.02–05.15 показывают всю колоду. По новому уточнению владельца карточка заполняет 430×932 без белого низа; постоянных кнопок «Интересно / Не сейчас» нет. Внизу только два круга: отмена слева и двухэтапный выход к условиям справа. Спецификация: `SWIPE_BEHAVIOR.md`, актуальная карта этой ветки: `swipe-flow-v2.json`.

В Penpot поддерживаются click/hover/after-delay, но нет drag-триггера. Для **ревью** нажатие по левой/правой области изображения показывает соответствующее состояние «Не сейчас / Интересно», затем следующую карточку. Это не настоящее распознавание свайпа и не запись предпочтений. В веб-приложении обычный tap по изображению не должен регистрировать реакцию.

06/07 и варианты `.left/.right` — демонстрационные состояния обратной связи; `.hint/.hint-left/.ready` — одноразовое обучение без выбора; `.continue` — раскрытая плашка; `.done` — завершение колоды. Это варианты компонентов, не новые самостоятельные разделы продукта.

### Свайп-feedback · применено в native Penpot

20 октября 2026 точечно обновлены **32 состояния**: 30 `.right/.left` и два обучающих `05.hint` / `05.hint-left`. Вправо — обычное Lucide-сердечко и «Интересно», влево — «Не сейчас». Рамки, контейнеры и цветные плашки feedback убраны; full-bleed изображения, логотип, контролы и переходы не пересобирались.

Сохранённая серверная версия: **`QETTYQ · 32 swipe feedback states · plain heart and text`**. Она дополнительно найдена через `File.findVersions()` как именованная, не autosave-версия; file revision 40 на момент проверки. Native изменения хранятся в Docker Penpot, а не только в памяти MCP-плагина.

Доказательства: `swipe-feedback-patch-report.json`, визуально проверенные `previews/06.png` и `previews/07.png`. У bounded-проверки 32 фреймов нет изменений остальных прямых слоёв; 192 взаимодействия уровня board/direct children сохранили свои targets и число. Это ограниченная проверка точечного патча, не новый полный аудит всех вложенных взаимодействий и не runtime E2E.

Повторяемый инструмент: `scripts/patch-penpot-swipe-feedback.mjs` (по умолчанию read-only; `--apply` — точечное изменение). Работает пакетами максимум по три фрейма, без глобального поиска каждого shape. Для обычного просмотра сохранённых макетов MCP/plugin servers не нужны.

Карты — подписанные схематические provider-replaceable слои, не картографические данные. Геолокация и AI-запросы не выполняются. Сохранение/модерация/удаление/системный share являются макетами состояний, не доказательством backend.

## Локальные контракты и доказательства

- `screen-content.json` — тексты и заполнение44 основных макетов.
- `flow-links.json` — полный контракт332 переходов и условных outcomes; не все служебные outcomes отображаются кнопками.
- `board-index.json` — actual Penpot IDs.
- `UX_REVIEW.md` — сценарный аудит и исправленные противоречия.
- `visual-audit.json`, `previews/` — проверка границ и native exports.
- `SWIPE_BEHAVIOR.md`, `swipe-flow-v2.json` — актуальная колода вместо прежних видимых reaction CTA.
- `CHAT_UI_SPEC.md` — беседа, обработка, карточки, повторный запрос и служебные состояния.
- `FEED_CAROUSEL.md` — горизонтальная выдача; просмотр не равен like/skip.
- `CONTROL_AUDIT.md`, `SURFACE_BOUNDS_AUDIT.md` — дизайнерские замечания и after-fix проверка.
- `control-audit-after.json` — повторный native scan147: enabled кнопок без действия0, геометрических пересечений текста0, выходов текста0. Не заменяет ручной прогон каждого runtime-действия.
- `review-links.json` — актуальные ссылки просмотра; после создания новых фреймов старые числовые index в вкладках могут смещаться. Обновлять страницу и открывать свежие ссылки.

Поля открывают выбранные **примеры** настроек, не живые HTML forms. Чат показывает фиксированный сценарий, не ответ модели на произвольный текст. Native click/after-delay показывают состояния; storage/API/system clipboard не выполняются.

Публичный сайт и app-код в этом дизайн-проходе не обновлялись. Следующий этап — согласование композиции и компонентов, затем перенос в приложение.
