# Sxodim pilot snapshot

`sxodim-astana-2026-10-20.json` contains facts actually retrieved from public Sxodim Astana event pages on 20 October 2026, not synthetic events. Each record retains publisher credit, the source URL and fetchedAt. Image files and descriptions are not included.

Third-party data is **not automatically covered by the code repository's license**. The publisher's [reuse terms](https://sxodim.com/polzovatelskoe-soglashenie) allow noncommercial use with author mention and links. This snapshot and the live adapter are scoped to the noncommercial QETTYQ pilot; commercial reuse requires separate permission. Preserve `requiredCredit` in public UI and any redistribution. This is not a partnership or a free/open commercial data license.

This dated file is a **snapshot fallback**, never proof of a working live fetch. Live status requires the runtime `/api/events` response with a fresh fetchedAt and successful source refresh. Uncertain prices, language, availability, duration and coordinates remain explicitly unknown.
